# VisionMate — Play Store Listing

## App Title

**VisionMate — Smart Navigation for the Blind**

## Short Description (80 chars)

AI-powered assistant with voice commands, object detection & emergency SOS.

## Full Description

VisionMate is an AI-powered navigation assistant designed for visually impaired users. Using your phone's camera and advanced object detection, VisionMate identifies obstacles, reads text, recognizes faces, and provides real-time voice guidance to help you move safely and independently.

### Key Features

🎯 **Real-Time Object Detection** — Detects 80+ objects using YOLOv8 AI model
🗣️ **Voice-First Interface** — Full control via voice commands in English and Hindi
📏 **Smart Distance Estimation** — Tells you exactly how far objects are in steps
🚦 **Traffic & Crosswalk Detection** — Warns about traffic lights and crossings
🧭 **Scene Understanding** — Identifies kitchens, roads, offices, and more
👤 **Face Recognition** — Remember and recognize familiar faces by voice
📡 **Indoor Navigation** — BLE beacon support for buildings and malls
🆘 **Emergency SOS** — One-tap emergency with GPS location sharing
📱 **Fall Detection** — Auto-alerts contacts if a fall is detected
🔊 **Spatial Audio** — Directional audio cues (left, right, ahead)
📖 **OCR Text Reading** — Reads signs, labels, and documents aloud
💰 **Currency Recognition** — Identifies Indian Rupee notes
🎓 **Guided Onboarding** — Any user ready in under 5 minutes
🔋 **Battery Optimized** — Under 15% battery per hour
📊 **Daily Summary** — End-of-day voice report of your activity

### Accessibility

✅ Large touch targets (80-100px)
✅ High contrast mode
✅ Beginner mode with simplified controls
✅ Voice-controlled settings and navigation

### Permissions
